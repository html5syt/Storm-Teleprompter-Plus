## 测试前准备

### 环境要求

- **平台**: Windows 10/11 (x64)
- **编译目标**: `build\windows\x64\runner\Debug\storm_teleprompter_plus.exe`
- **网络**: 测试 LAN 共享时需要局域网连接
- **工具**: 
  - Dart/Flutter SDK (用于修改后重新编译)
  - 文本编辑器 (用于查看日志)

### 启动应用

```bash
# 方法 1: 编译后直接运行
flutter run -d windows

# 方法 2: 执行编译产物
.\build\windows\x64\runner\Debug\storm_teleprompter_plus.exe

# 方法 3: 通过 VS Code 调试
flutter run -d windows --debug
```

### 日志查看

```bash
# 在终端启动应用时可看到日志输出
# 关键日志前缀:
[BackendServer]      # 后端服务
[TeleprompterProvider] # 提词器状态
[HomeLogic]          # 首页逻辑
[SettingsProvider]   # 设置状态
```

## 功能测试用例

### TC-1: 字体分离 (Font Separation)

**测试步骤:**

1. **打开应用** 
   - 应显示"飓风提词器"首页
   - 验证默认字体为系统默认

2. **进入设置 - 应用字体**
   - 点击首页右上角"设置"按钮
   - 选择"应用字体"卡片
   - 点击当前字体（默认为空或系统默认）
   - 预期: 弹出字体列表对话框
   ```
   字体选择:
   ○ Noto Sans SC (思源黑体简体)
   ○ Noto Serif SC (思源宋体简体)
   ○ 思源黑体
   ○ 思源宋体
   [其他 11 种预设字体...]
   ```

3. **选择字体**
   - 选择"Noto Sans SC"
   - 返回设置页
   - 观察应用 UI 所有文本（标题、菜单、对话框）
   - 预期: 所有 UI 文本使用新选择的字体

4. **创建或编辑稿件**
   - 新建一篇稿件或打开已有稿件
   - 编辑内容，添加中文文本
   - 进入提词模式

5. **进入提词器 - 正文显示 - 字体**
   - 点击右侧"正文显示"面板
   - 找到"字体"选项
   - 点击当前字体（可能显示"思源黑体"或其他）
   - 预期: 弹出字体列表
   - 选择不同于应用字体的字体（例如选"Noto Serif SC"）
   - 观察提词文本
   - 预期: **仅提词文本字体改变，应用 UI 字体保持不变**

6. **验证独立性**
   - 应用字体: Noto Sans SC (无衬线)
   - 提词字体: Noto Serif SC (有衬线)
   - 两者应互不影响

**预期结果**: ✅ 两种字体可独立设置且互不影响

### TC-2: 进度条显示切换 (Progress Bar Toggles)

**测试步骤:**

1. **启动提词模式**
   - 打开任意稿件
   - 点击"开始提词"进入提词模式
   - 观察顶部进度条

2. **查看默认显示项**
   - 预期显示: `时间 | 百分比 | 速度 | 当前时间`
   - 例: `00:05 | 45% | 1.2×  | 14:32:15`

3. **打开设置面板**
   - 点击右侧"正文显示"面板
   - 向下滚动找到"进度显示"部分
   - 预期看到 4 个切换开关:
   ```
   ☑ 显示时间
   ☑ 显示百分比
   ☑ 显示速度
   ☑ 显示当前时间
   ```

4. **逐项测试隐藏**

   **4a. 隐藏时间**
   - 点击"显示时间"的开关变为 ☐
   - 观察进度条
   - 预期: 时间显示消失，其他项保留
   - 进度条从 `00:05 | 45% | 1.2× | 14:32:15` 变为 `45% | 1.2× | 14:32:15`

   **4b. 隐藏百分比**
   - 点击"显示百分比"的开关变为 ☐
   - 预期: 百分比消失，例 `00:05 | 1.2× | 14:32:15`

   **4c. 隐藏速度**
   - 点击"显示速度"的开关变为 ☐
   - 预期: 速度消失，例 `00:05 | 45% | 14:32:15`

   **4d. 隐藏当前时间**
   - 点击"显示当前时间"的开关变为 ☐
   - 预期: 时钟显失，例 `00:05 | 45% | 1.2×`

5. **组合测试**
   - 只保留"显示时间"和"显示速度"
   - 预期: `00:05 | 1.2×`（其他项空白被删除，不留间隙）

6. **刷新验证**
   - 暂停提词
   - 重新开始提词
   - 预期: 切换配置仍然保持

**预期结果**: ✅ 4 项显示可独立切换，进度条正确更新

### TC-3: 长行文本渲染 (Long-line Rendering)

**测试步骤:**

1. **创建包含长行的稿件**
   - 打开编辑页面或创建新稿件
   - 输入一行很长的文本（80+ 汉字或 150+ 英文字符）
   - 例:
   ```
   这是一个很长很长很长很长很长很长很长很长的测试行，用来验证长行是否能够正确处理和滚动显示而不被截断
   ```

2. **进入提词模式**
   - 点击"开始提词"
   - 等待提词器滚动到长行

3. **验证长行显示**
   - 预期: 长行未被截断（不显示 "..." ）
   - 长行可能超出屏幕宽度，但完整保留在一行内
   - 预期可见部分显示行首内容

4. **测试水平滚动**
   - 在长行上使用鼠标滚轮：向右滚动
   - 预期: 文本水平向左移动，露出被隐藏的部分
   - 继续滚动直到看到行尾

5. **使用键盘导航**
   - 点击长行上的任意字符
   - 按右箭头键逐字移动
   - 预期: 光标移动时自动水平滚动保持光标可见

6. **边界情况**
   - 测试中英文混合的长行
   - 测试包含特殊符号的长行
   - 预期: 都能正常水平滚动显示

**预期结果**: ✅ 长行完整显示，可水平滚动查看

### TC-6: 局域网共享 (LAN Sharing)

**测试步骤（单机测试）:**

1. **查看后端状态**
   - 启动应用
   - 点击首页右上角连接图标（或菜单）
   - 预期显示:
   ```
   本机后端
   本地后端 (端口: XXXX)
   设备: 0
   ID: [client-id]
   ```

2. **启用 LAN 发布（如果有 UI）**
   - 进入设置 > 后端共享配置
   - 查看"公开到局域网"选项
   - 如果有切换，确认开启状态
   - 预期: 后端在 0.0.0.0:port 上监听（接受远程连接）

**测试步骤（多机测试，需要两台电脑）:**

3. **获取主机信息**
   - 在主机（运行应用的电脑）上:
     - 打开设置 > 后端共享配置
     - 查看"本机 IP"或"端口"信息
     - 例: `192.168.1.100:8080`

4. **在远程机器连接**
   - 在另一台电脑上启动应用
   - 等待本地连接建立
   - 点击首页右上角连接菜单
   - 选择"连接到远程后端"
   - 输入主机 IP 和端口（例 `192.168.1.100:8080`）
   - 点击"连接"

5. **验证连接**
   - 预期: 连接状态变为"远程后端 (192.168.1.100:8080)"
   - 预期: 远程机器的设备列表更新为 1（表示有外部连接）

6. **数据同步测试**
   - 在主机上新建/编辑稿件
   - 在远程机器上刷新（断开后重连或手动刷新）
   - 预期: 远程机器能看到主机的稿件

**预期结果**: ✅ 可连接到远程后端，设备计数正确

## 后端架构测试

### TC-7: 多客户端连接警告 (Multi-client Warning)

**测试步骤（需要多机环境）:**

1. **启动主机应用**
   - 在 A 电脑上启动应用（本地后端模式）

2. **连接第一个外部客户端**
   - 在 B 电脑上启动应用
   - 连接到 A 的远程后端
   - 验证 A 的设备列表显示 1 个外部设备

3. **连接第二个外部客户端**
   - 在 C 电脑上启动应用
   - 连接到 A 的远程后端
   - 验证 A 的设备列表显示 2 个外部设备

4. **触发退出警告**
   - 在 A 电脑上尝试关闭应用
   - 方法:
     - 按 Alt+F4
     - 或点击应用窗口关闭按钮
     - 或按 Android 返回键（如支持）

5. **验证警告对话框**
   - 预期显示 AlertDialog:
   ```
   确认退出
   ⚠️ 检测到有外部设备正在连接到本机后端
   当前连接数: 2
   强行退出将中断外部连接。是否继续？
   
   [保留运行] [强制退出]
   ```

6. **测试选择**
   - 点击"保留运行"
   - 预期: 对话框关闭，应用继续运行，B/C 仍连接
   
   - 重试退出
   - 点击"强制退出"
   - 预期: 应用关闭，B/C 的连接中断

7. **单客户端时无警告**
   - 断开 B 或 C 的连接，保留只有 1 个
   - 尝试在 A 上关闭应用
   - 预期: 直接关闭，不显示警告

**预期结果**: ✅ 多客户端时显示警告，单客户端时无警告

## 问题排查

### 问题 1: 编译失败

**症状**: `flutter build windows --debug` 返回错误

**检查清单**:
```
□ 确认 Flutter SDK 已安装: flutter --version
□ 确认在项目根目录: ls pubspec.yaml
□ 清理缓存: flutter clean
□ 重新获取依赖: flutter pub get
□ 检查 Dart 版本兼容性
```

**解决方案**:
```bash
flutter clean
flutter pub get
flutter build windows --debug
```

---

### 问题 2: 字体显示不变

**症状**: 改变字体设置后，UI 或提词文本仍使用旧字体

**检查清单**:
```
□ 确认字体已正确保存（SettingsProvider 中 notifyListeners 被调用）
□ 重启应用验证
□ 查看日志中是否有字体加载错误
```

**日志搜索**:
```
[SettingsProvider] 已设置应用字体为: ...
[SettingsProvider] 已设置提词字体为: ...
```

---

### 问题 3: 进度条显示异常

**症状**: 进度条项目无法隐显，或空间排列错误

**检查清单**:
```
□ 确认 TeleprompterProvider 中的 toggle 方法被调用
□ 查看 teleprompter_page.dart 中的条件判断是否正确
□ 手动重启提词重新加载配置
```

**测试日志**:
```
[TeleprompterProvider] toggleProgressShowTime: true -> false
[TeleprompterProvider] toggleProgressShowTime: false -> true
```

---

### 问题 4: 长行文本仍被截断

**症状**: 长行显示为 "文本..." 而不是完整内容

**原因**: SingleChildScrollView 未正确包装或 overflow 设置错误

**检查代码**:
```dart
// 在 lib/widgets/teleprompter_text_layer.dart 中验证
SingleChildScrollView(
  scrollDirection: Axis.horizontal,
  child: RichText(
    text: TextSpan(...),
    maxLines: 1,
    overflow: TextOverflow.visible,  // 关键
  ),
)
```

---

### 问题 5: 远程连接失败

**症状**: 连接到远程后端显示"连接失败"

**检查清单**:
```
□ 确认主机已启动应用且后端正在运行
□ 确认 IP 地址正确: ping 主机IP
□ 确认端口号正确: 检查主机的连接信息
□ 确认防火墙未阻止连接
□ 确认两台电脑在同一局域网
```

**防火墙配置（Windows）**:
```powershell
# 允许应用通过防火墙
netsh advfirewall firewall add rule name="Flutter App" `
  dir=in action=allow program="C:\path\to\app.exe" `
  protocol=tcp localport=8080
```

---

### 问题 6: 多客户端警告不显示

**症状**: 有多个客户端连接但尝试退出时无警告

**检查清单**:
```
□ 确认 BackendServer.clientCount >= 2
□ 查看日志是否有"检测到多个客户端连接"
□ 确认在本地模式，不是远程模式
□ 确认使用 PopScope 拦截的正确的退出事件
```

**日志搜索**:
```
[BackendServer] ⚠️ 检测到多个客户端连接 (2 个)
[HomeLogic] 检查多客户端失败: ...
```
