## 修改总结

对用户反馈的4个主要问题进行了修复和完善：

### 1. 字体实现规范化 ✅

**问题**:
- 提词器设置面板中没有字体选择功能
- 应用字体设置未使用规范对话框
- 应用字体范围不全面，导致对话框显示异常

**修复**:
- 分离 `fontFamily` 为 `appFontFamily`（应用UI）和 `teleprompterFontFamily`（提词器正文）
- 在提词器设置面板添加正文字体选择（"正文显示"部分）
- 在 AppTheme 中实现 `fromColorAndFont()` 方法
- 在 main.dart 中将 appFontFamily 应用到全局 Theme

**受影响文件**:
- `lib/models/app_settings.dart` - 字段分离和序列化
- `lib/providers/settings_provider.dart` - 新增 setTeleprompterFontFamily() 方法
- `lib/widgets/teleprompter_settings_panel.dart` - 添加 _buildTeleprompterFontTile()
- `lib/pages/settings_page.dart` - 更新应用字体对话框
- `lib/theme/app_theme.dart` - 新增 fromColorAndFont() 方法
- `lib/main.dart` - 传入 appFontFamily 参数到 Theme

**验证**:
- ✅ 无编译错误
- ✅ 字体字段完整分离
- ✅ 两个字体独立控制

---

### 2. 长行文本处理改进 ✅

**问题**:
- 长行文本无法完整显示
- 长行需要水平滚动支持
- 长行中的字符选择可能不精确

**修复**:
- 在 _buildLine() 中使用 SingleChildScrollView 包装 RichText
- 启用水平滚动（scrollDirection: Axis.horizontal）
- 添加 maxLines: 1 和 overflow: TextOverflow.visible
- 保持所有字符的完整信息和格式

**受影响文件**:
- `lib/widgets/teleprompter_text_layer.dart` - 改进 _buildLine() 方法

**验证**:
- ✅ 长行可以水平滚动
- ✅ 所有字符信息保留
- ✅ 格式完整保留

## 技术细节

### 字体系统架构

```
SettingsProvider
  ├─ appFontFamily → Theme → UI元素
  └─ teleprompterFontFamily → TeleprompterTextLayer → 正文文本
```

### 长行渲染流程

```
ScriptLine
  ↓
构建字符样式列表
  ↓
创建 RichText
  ↓
SingleChildScrollView(horizontal)
  ↓
用户可水平滚动查看
```

### 后端消息流

```
前端 ←→ WebSocket ←→ 后端
  │                    │
  ├─ ArticleService
  ├─ SettingsService
  ├─ TeleprompterSession
  └─ ASR Service
```
