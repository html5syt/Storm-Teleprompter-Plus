```

```

## 迁移时间轴

```
2010-2015      2023-2024         2024-2026
  WinForms    →  React+NestJS  →  Flutter
   ❌                 ⚠️                ✓
 (维护中)      (原始产品)      (新产品推荐)
```

### 为什么迁移到 Flutter?

| 驱动因素       | 说明                          |
| -------------- | ----------------------------- |
| **跨平台需求** | 需要支持 Mac/Linux 用户       |
| **现代化**     | Material Design 3, 最新技术栈 |
| **单体架构**   | 不需要后端，减少部署复杂度    |
| **性能**       | Dart 编译执行，性能优于 Web   |
| **用户体验**   | 原生应用感受，离线工作        |

## 快速诊断表

### 当遇到问题时...

| 问题     | Flutter                | React+NestJS        | WinForms               |
| -------- | ---------------------- | ------------------- | ---------------------- |
| 性能慢   | 检查 ListView.builder  | 检查 Redux 订阅     | 检查 Invalidate() 频率 |
| UI 崩溃  | 检查 Provider 生命周期 | 检查 React 依赖数组 | 检查事件处理异常       |
| 数据丢失 | 检查 StorageService    | 检查 API 失败       | 检查 Registry 权限     |
| 内存溢出 | 检查资源释放           | 检查闭包循环        | 检查 GDI 对象泄漏      |
| 网络超时 | 增大 http 超时         | 检查 Axios 配置     | 增大 HttpClient 超时   |
