# 快速模式与匀速滚动验证记录

日期：2026-10-01
需求来源：`prompt_fast_scroll.md`，以及后续关于隐藏快速模式返回按钮、统一编辑器工具栏、移除 Web 构建的补充要求。

## 需求核对

| 需求 | 实现与验证证据 |
| --- | --- |
| 快速模式默认关闭，开启后进入空编辑器 | `HomeQuickMode` 等待设置和目录加载后初始化一次；`quick_mode_test.dart` 验证普通启动和快速启动 |
| 稿件管理浮动按钮、加号上方的返回编辑器按钮 | 首页与编辑器保留同一快速会话；列表往返测试验证编辑器实例和草稿内容不丢失 |
| 手动保存、红色未保存提示、选择保存目录 | `EditorQuickMode.manualSave`、共用目录选择器；测试覆盖保存成功、失败、取消与目标目录 |
| 自动保存默认关闭、默认根目录，可选择默认目录 | 全局 `quickModeEnabled` / `quickModeAutoSave` / `quickModeFolderId` 完整序列化；测试验证目录选项启用条件及同一稿件自动更新 |
| 退出应用或切换稿件前询问保存 | `confirmLeave` 被窗口关闭、系统退出和稿件切换共用；测试验证隐藏草稿也受到保护，取消退出后内容仍在 |
| 选择其他稿件后结束本次快速模式 | `_finishQuickMode` 确认后销毁临时编辑器，不改变下次启动设置；测试确认返回列表后不再出现快速编辑器按钮 |
| 未保存稿件直接提词 | 使用内存稿件快照，不强制落盘；测试验证正文已进入提词页、仓库没有写入 |
| 自动按行 / 匀速标签切换，语音模式恢复“自动”标签 | 页面级测试在 390px 和 1000px 宽度验证真实标签与设置状态 |
| 匀速按固定像素速度滚动、隐藏阅读区域和动态当前字标记 | 帧时间积分驱动；混合字号正文测试验证每秒位移和无字符吸附；页面测试验证阅读区域及其配置隐藏 |
| 十档像素速度、自由输入、两种自动模式支持负速度 | 十档递增预设、带符号输入、滚轮倍率、反向滚动和边界测试；各模式保留独立速度 |
| 零速停止，允许手动上下滑动 | 正文层测试验证零速拖动后保持实际像素位置，不自动回到某一行 |
| 进入提词页面时正文从底部先快后慢滑入 | `PromptEntrance`；几何测试验证初始位移、缓出速度、最终位置与刷新不重播 |
| 侧栏移除速度输入，保留“播放进度条”设置 | `teleprompter_panel_test.dart` 验证分组、四项显示开关和字号比例；调速统一在播放工具栏 |
| 快速模式左上角不显示返回按钮 | `automaticallyImplyLeading: !widget.quickMode`；测试验证快速模式隐藏、普通路由保留返回行为 |
| 编辑器工具栏整齐统一 | 共用 36px 按钮、20px 图标、4px 间距与边框；测试验证左对齐、实际图标尺寸、选中态、窄屏访问和真实格式操作 |
| 移除 Web 构建目标 | 删除 `web/`，清理平台元数据、图标配置、工作流及说明；`native_platform_targets_test.dart` 验证仅保留五个原生平台 |
| Git 分功能提交 | 快速模式、滚动模式、入场动画、侧栏整理、工具栏与 Web 目标移除均有独立提交 |
