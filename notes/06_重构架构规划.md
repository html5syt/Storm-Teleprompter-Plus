## WebSocket 通信协议

### 消息格式
```json
{
  "type": "message_type",
  "data": { ... },
  "id": "request_id"  // 可选，用于请求-响应配对
}
```

### 消息类型
- `article:list` / `article:list_response`
- `article:create` / `article:create_response`
- `article:update` / `article:update_response`
- `article:delete` / `article:delete_response`
- `article:get` / `article:get_response`
- `folder:list` / `folder:create` / `folder:delete` / `folder:rename`
- `settings:get` / `settings:save`
- `teleprompter:sync` (当前字同步)
- `teleprompter:start_session` / `teleprompter:end_session`
- `asr:result` (ASR识别结果)
- `connection:info` (连接信息)
- `error` (错误消息)

## 优先实现顺序

1. **前后端分离基础架构** - WebSocket server/client, 协议定义
2. **后端服务层** - ArticleService, SettingsService (保持SharedPreferences)
3. **前端Provider重构** - 通过WS与后端通信
4. **正文容器渲染优化** - 懒加载, 仅渲染可见区域
5. **阅读区域框修复** - 当前字位置实时跟随
6. **提词器叠加层完善** - 设置面板, 控制栏
