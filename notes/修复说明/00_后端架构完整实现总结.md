## 🏗️ 后端架构改动详解

### 1️⃣ 多客户端连接监控（优先级：关键）

**需求**: 当本机后端有 2 个或以上外部客户端连接时，用户尝试退出应用应显示警告。

**实现方案**:
```
后端服务启动
    ↓
BackendServer 定期检查 clientCount
    ↓
if (clientCount >= 2) → 标记 hasMultipleClients = true
    ↓
用户尝试退出（按 Alt+F4 / 点关闭 / 返回键）
    ↓
PopScope 拦截退出事件
    ↓
HomeLogic._checkMultiClientBeforeExit() 检查后端状态
    ↓
if (hasMultipleClients) → 显示 AlertDialog 警告
    ↓
用户选择 "保留运行" 或 "强制退出"
```

**关键代码**:

```dart
// lib/backend/backend_server.dart
bool get hasMultipleClients => _hasMultipleClients;

void _monitorClientCount() {
  _clientCountSubscription = Stream.periodic(
    const Duration(seconds: 1),
  ).listen((_) {
    final isMultiple = wsServer.clientCount >= 2;
    if (isMultiple != _hasMultipleClients) {
      _hasMultipleClients = isMultiple;
      if (_hasMultipleClients) {
        debugPrint('[BackendServer] ⚠️ 检测到多个客户端连接...');
      }
    }
  });
}

// lib/pages/home_page.dart
return PopScope(
  canPop: true,
  onPopInvokedWithResult: (didPop, result) async {
    if (didPop) return;
    await _checkMultiClientBeforeExit(context);
  },
  child: Scaffold(...),
);

// lib/pages/home_logic.dart
Future<void> _checkMultiClientBeforeExit(BuildContext context) async {
  if (!connection.isLocal) {
    Navigator.pop(context);
    return;
  }
  
  final clientCount = globalBackendServer.clientCount;
  if (clientCount >= 2) {
    await _showMultiClientWarning(context, clientCount);
  } else {
    Navigator.pop(context);
  }
}
```

### 2️⃣ 远程后端 UI 隐藏（优先级：关键）

**需求**: 连接到远程后端时，隐藏与本地管理相关的 UI（稿件管理、ASR、后端配置），保留全局偏好设置。

**实现方案**:

```
连接到本地后端
    ↓ connection.isLocal = true
    ↓
显示完整 UI:
├─ 搜索栏 ✓
├─ 稿件列表 ✓
├─ 新建按钮 ✓
├─ 设置 > ASR ✓
└─ 设置 > 后端配置 ✓

                或

连接到远程后端
    ↓ connection.isRemote = true
    ↓
隐藏本地管理 UI:
├─ 搜索栏 ✗
├─ 稿件列表 → 显示提示 (☁️ 远程后端模式)
├─ 新建按钮 ✗
├─ 设置 > ASR ✗
└─ 设置 > 后端配置 ✗

保留全局设置:
├─ 应用主题 ✓
├─ 应用字体 ✓
├─ 重置 ✓
└─ 关于 ✓
```

**关键代码**:

```dart
// lib/pages/home_page.dart - 隐藏搜索栏
Widget _buildSearchBar() {
  return Consumer<ConnectionProvider>(
    builder: (context, connection, _) {
      if (connection.isRemote) {
        return const SliverToBoxAdapter(child: SizedBox.shrink());
      }
      return SliverToBoxAdapter(child: TextField(...));
    },
  );
}

// lib/pages/home_page.dart - 显示远程模式提示
Widget _buildArticleGrid() {
  return Consumer2<ArticleProvider, ConnectionProvider>(
    builder: (context, articleProvider, connection, _) {
      if (connection.isRemote) {
        return SliverFillRemaining(
          child: Center(
            child: Column(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                Icon(Icons.cloud_done, size: 64),
                const Text('远程后端模式'),
                const Text('本地稿件管理已隐藏'),
                Text('当前连接: ${connection.connectionInfoText}'),
                ElevatedButton.icon(
                  onPressed: () => connection.disconnect(),
                  icon: const Icon(Icons.cloud_off),
                  label: const Text('断开连接'),
                ),
              ],
            ),
          ),
        );
      }
      // ... 显示本地稿件列表
    },
  );
}

// lib/pages/settings_page.dart - 条件性隐藏 ASR 和后端配置
if (!connection.isRemote) ...[
  _buildSectionHeader(context, '语音识别模型'),
  const SizedBox(height: 12),
  _buildAsrSection(context, provider, settings),
  const SizedBox(height: 24),
],

if (!connection.isRemote) ...[
  _buildSectionHeader(context, '后端共享配置'),
  const SizedBox(height: 12),
  _buildBackendSection(context, connection),
  const SizedBox(height: 24),
],
```

## 🎯 设计原则

### 1. 优雅的 UI 适配
- 使用 `Consumer` 和 `if-else` 进行条件渲染
- 远程模式显示友好提示而不是空白
- 无缝的本地/远程切换体验

### 2. 可靠的事件拦截
- 使用 Flutter 3.16+ 的 `PopScope` API
- 完整拦截 Alt+F4、关闭按钮、返回键等所有退出事件
- 拦截逻辑与 UI 层充分解耦

### 3. 高效的监控机制
- 定期轮询 (1 秒) 而非事件驱动（简化 WsServer 改动）
- 状态变化时仅打印日志，不影响性能
- 允许快速扩展为事件驱动架构

### 4. 健全的错误处理
- 多个防守条件 (context.mounted 检查)
- 导航时进行 context 可用性验证
- 异常场景下优雅降级
