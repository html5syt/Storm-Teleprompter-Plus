### 1. lib/backend/backend_server.dart

**变更内容**: 新增多客户端连接监控功能

**新增字段** (第 9-12 行):

**新增方法** (第 80-102 行):
```dart
/// 监控客户端连接数变化
void _monitorClientCount() {
  // 初始检查
  _hasMultipleClients = wsServer.clientCount >= 2;

  // 定期检查客户端连接数（每秒一次）
  _clientCountSubscription = Stream.periodic(
    const Duration(seconds: 1),
  ).listen((_) {
    final newCount = wsServer.clientCount;
    final isMultiple = newCount >= 2;

    if (isMultiple != _hasMultipleClients) {
      _hasMultipleClients = isMultiple;
      if (_hasMultipleClients) {
        debugPrint('[BackendServer] ⚠️ 检测到多个客户端连接 ...');
      }
    }
  });
}
```

**集成点**:
- `start()` 方法中: 添加 `_monitorClientCount();`
- `stop()` 方法中: 添加 `_clientCountSubscription?.cancel();` 和 `_hasMultipleClients = false;`

**改动统计**: +40 行代码

### 4. lib/pages/home_logic.dart

**变更内容**: 多客户端警告检查和显示

**新增方法** (第 264-291 行):
```dart
/// 检查是否有多个客户端连接，如果有则显示警告
Future<void> _checkMultiClientBeforeExit(BuildContext context) async {
  if (!context.mounted) return;

  final connection = context.read<ConnectionProvider>();

  // 本地连接模式才需要检查
  if (!connection.isLocal) {
    if (context.mounted) Navigator.pop(context);
    return;
  }

  // 检查全局 BackendServer 中的客户端数
  final clientCount = globalBackendServer.clientCount;
  final hasMultipleClients = clientCount >= 2;

  if (hasMultipleClients) {
    await _showMultiClientWarning(context, clientCount);
  } else {
    if (context.mounted) Navigator.pop(context);
  }
}
```

**新增方法** (第 293-330 行):
```dart
/// 显示多客户端连接警告对话框
Future<void> _showMultiClientWarning(BuildContext context, int clientCount) async {
  return showDialog(
    context: context,
    barrierDismissible: false,
    builder: (ctx) => AlertDialog(
      title: const Text('确认退出'),
      content: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          const Text('⚠️ 检测到有外部设备正在连接到本机后端'),
          const SizedBox(height: 8),
          Text(
            '当前连接数: $clientCount',
            style: const TextStyle(fontSize: 13, color: AppColors.textMuted),
          ),
          const SizedBox(height: 12),
          const Text(
            '强行退出将中断外部连接。是否继续？',
            style: TextStyle(
              color: AppColors.warning,
              fontWeight: FontWeight.w500,
            ),
          ),
        ],
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(ctx),
          child: const Text('保留运行'),
        ),
        TextButton(
          onPressed: () {
            Navigator.pop(ctx);
            if (context.mounted) Navigator.pop(context);
          },
          style: TextButton.styleFrom(foregroundColor: AppColors.error),
          child: const Text('强制退出'),
        ),
      ],
    ),
  );
}
```
