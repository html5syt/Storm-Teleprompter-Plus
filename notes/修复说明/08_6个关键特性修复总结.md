## 功能修复清单

### 1. 字体分离 (Font Separation)

**问题**: 无法独立设置应用 UI 字体和提词器文本字体

**解决方案**:
- `appFontFamily`: 用于整个应用 UI 主题
- `teleprompterFontFamily`: 仅用于提词器文本显示
- 在 `AppSettings` 中分离，在 `SettingsProvider` 中提供独立 setter

**涉及文件**:
- `lib/models/app_settings.dart`: 新增两个字段
- `lib/providers/settings_provider.dart`: 新增 setAppFontFamily() 和 setTeleprompterFontFamily()
- `lib/theme/app_theme.dart`: fromColorAndFont() 接收 fontFamily 参数
- `lib/main.dart`: 传递 appFontFamily 到 Theme
- `lib/pages/settings_page.dart`: UI 中显示应用字体选择
- `lib/widgets/teleprompter_settings_panel.dart`: UI 中显示提词器字体选择

**UI 表现**:
```
设置 > 应用字体  [Noto Sans SC ▼]    ← 全局应用 UI
提词器 > 正文显示 > 字体 [思源黑体 ▼]  ← 仅提词器文本
```

✅ **验证**: 可独立选择两种字体，主题正确应用

### 2. 进度条显示切换 (Progress Bar Toggles)

**问题**: 进度条的时间、百分比、速度、当前时间显示无法独立控制

**解决方案**:
- 新增 4 个布尔字段: `progressShowTime`, `progressShowPercentage`, `progressShowSpeed`, `progressShowCurrentTime`
- 每个字段有独立 toggle 方法
- UI 中条件性渲染进度条项目

**涉及文件**:
- `lib/models/app_settings.dart`: 新增 4 个 boolean 字段
- `lib/providers/settings_provider.dart`: 新增 4 个 toggle 方法
- `lib/widgets/teleprompter_settings_panel.dart`: 新增 4 个 toggle 开关
- `lib/pages/teleprompter_page.dart`: 条件性显示进度条项目

**UI 表现**:
```
提词器 > 正文显示
├─ 显示时间    [ON/OFF]
├─ 显示百分比  [ON/OFF]
├─ 显示速度    [ON/OFF]
└─ 显示当前    [ON/OFF]
```

✅ **验证**: 进度条项目可独立隐显

### 3. 长行文本渲染 (Long-line Rendering)

**问题**: 超长文本行被 Overflow.ellipsis 截断，无法查看完整内容

**解决方案**:
- 使用 `SingleChildScrollView(scrollDirection: Axis.horizontal)` 包装 RichText
- 设置 `maxLines: 1` 和 `overflow: TextOverflow.visible`
- 用户可水平滚动查看长行

**涉及文件**:
- `lib/widgets/teleprompter_text_layer.dart`: _buildLine() 中包装 SingleChildScrollView

**代码示例**:
```dart
SingleChildScrollView(
  scrollDirection: Axis.horizontal,
  physics: const BouncingScrollPhysics(),
  child: RichText(
    text: TextSpan(children: textSpans),
    maxLines: 1,
    overflow: TextOverflow.visible,
  ),
),
```

✅ **验证**: 长行文本可水平滚动显示

## 后端架构改进

### 改进 1: 多客户端连接监控

**需求**: 本机后端有多个外部连接时，退出需要警告

**实现**:
- `BackendServer._monitorClientCount()`: 定期检查客户端数
- `HomeLogic._checkMultiClientBeforeExit()`: 拦截退出事件
- `HomeLogic._showMultiClientWarning()`: 显示警告对话框

**流程**:
```
用户按返回键 / 关闭应用
        ↓
PopScope.onPopInvokedWithResult 触发
        ↓
_checkMultiClientBeforeExit() 检查客户端数
        ↓
if (clientCount >= 2) 显示警告对话框
        ↓
用户选择 "保留运行" 或 "强制退出"
```

✅ **验证**: 多客户端时显示警告

---

### 改进 2: 远程后端 UI 隐藏

**需求**: 连接到远程后端时，隐藏本地管理的 UI

**隐藏项**:
- 搜索栏（无本地数据）
- 稿件列表（显示"远程后端模式"提示）
- 新建稿件按钮（不允许本地创建）
- ASR 模型选择（远程管理）
- 后端配置（远程管理）

**保留项**:
- 应用主题
- 应用字体
- 关于/帮助

**实现**:
- `home_page.dart`: `if (connection.isRemote) { 显示提示 }`
- `settings_page.dart`: `if (!connection.isRemote) { 显示 ASR/后端配置 }`

✅ **验证**: 远程模式下 UI 正确隐显
