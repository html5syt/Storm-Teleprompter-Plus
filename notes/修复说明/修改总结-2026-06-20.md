## 相关技术

### 字体系统架构
```
SettingsProvider
  ├─ appFontFamily → Theme → 应用UI
  └─ teleprompterFontFamily → TeleprompterTextLayer → 正文文本
```

### 长行渲染
```
ScriptLine
  ↓
字符样式列表
  ↓
RichText
  ↓
SingleChildScrollView(horizontal)
  ↓
用户可水平滚动
```
