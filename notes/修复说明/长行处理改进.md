# 长行文本处理改进

## 问题描述

提词器正文容器对单个长行处理不正确，主要表现为：
1. 长行文本无法完整显示
2. 长行需要支持水平滚动
3. 点击长行时的字符选择可能不精确

## 改进方案

### 实现细节

**文件**: `lib/widgets/teleprompter_text_layer.dart`

#### 核心改动

1. **使用 SingleChildScrollView 提供水平滚动**
   ```dart
   SingleChildScrollView(
     scrollDirection: Axis.horizontal,
     physics: const BouncingScrollPhysics(),
     child: RichText(
       text: TextSpan(children: textSpans),
       maxLines: 1,
       overflow: TextOverflow.visible,
     ),
   )
   ```

2. **保证完整的字符信息**
   - 预先计算所有字符的文本样式
   - 在 RichText 中完整保留所有字符
   - 使用 `maxLines: 1` 防止换行，`overflow: TextOverflow.visible` 允许超出容器

3. **精确的字符选择**
   - 点击行时选择第一个字符
   - 用户通过键盘左右箭头精确移动到其他字符
   - 保留所有字符的 `rawIndex` 信息用于精确定位

### 长行处理流程

```
输入: 长行文本（超过容器宽度）
  ↓
分割为单个字符，保留完整信息（颜色、加粗、下划线等）
  ↓
构建 TextSpan 列表
  ↓
使用 SingleChildScrollView（水平）包装 RichText
  ↓
用户可以水平滚动查看全部内容
  ↓
GestureDetector 处理点击事件
  ↓
输出: 当前字符索引
```

### 关键参数

- `scrollDirection: Axis.horizontal`: 启用水平滚动
- `physics: BouncingScrollPhysics()`: 使用 iOS 风格的弹性滚动
- `maxLines: 1`: 强制单行显示
- `overflow: TextOverflow.visible`: 允许文本超出容器范围（由 SingleChildScrollView 控制）
