# 字体实现规范修复

## 问题描述

原有实现中存在以下问题：
1. 提词器设置面板中没有字体选择功能
2. 应用字体设置未使用新的字体对话框
3. 应用字体设置范围不全面，某些对话框仍使用 Flutter 默认字体导致 CJK 区域显示错误

## 修复方案

### 1. 字体字段分离（✅ 已完成）

**文件**: `lib/models/app_settings.dart`

分离单一的 `fontFamily` 字段为：
- `appFontFamily`: 应用 UI 字体（包括所有对话框、设置页、标签等）
- `teleprompterFontFamily`: 提词器正文字体（仅用于文本渲染）

```dart
final String appFontFamily = 'Noto Sans SC';      // UI字体
final String teleprompterFontFamily = 'Noto Sans SC';  // 正文字体
```

### 2. 提词器设置面板中添加字体选择（✅ 已完成）

**文件**: `lib/widgets/teleprompter_settings_panel.dart`

在"正文显示设置"部分添加了字体选择 Tile：

```dart
_buildTeleprompterFontTile(context, provider, settings)
```

用户可以在提词器设置面板（右侧抽屉）中的"正文显示"部分选择提词器文字体。

支持的预设字体：
- 系统默认
- Noto Sans SC
- Noto Serif SC
- 思源黑体
- 思源宋体
- Microsoft YaHei
- SimSun
- KaiTi
- FangSong
- Roboto
- Arial

### 3. 应用字体全局应用（✅ 已完成）

**文件**: `lib/theme/app_theme.dart` 和 `lib/main.dart`

#### 修改应用主题构建方法

`AppTheme` 新增 `fromColorAndFont()` 方法，支持传入字体参数：

```dart
static ThemeData fromColorAndFont(
  Color primary, {
  String fontFamily = 'Noto Sans SC',
}) {
  // ...
  return ThemeData(
    fontFamily: fontFamily.isEmpty ? null : fontFamily,
    // ... 其他主题配置
  );
}
```

#### 在应用入口传入字体

`lib/main.dart` 中的 `MaterialApp` 配置：

```dart
Consumer<SettingsProvider>(
  builder: (context, settingsProvider, _) {
    final primary = AppColors.primaryFromSettings(
      settingsProvider.settings.uiPrimaryColor,
    );
    final appFont = settingsProvider.settings.appFontFamily;
    return MaterialApp(
      theme: AppTheme.fromColorAndFont(primary, fontFamily: appFont),
      darkTheme: AppTheme.fromColorAndFont(primary, fontFamily: appFont),
      // ...
    );
  },
)
```

### 4. 字体应用范围

设置的 `appFontFamily` 会通过 Theme 应用到：
- ✅ AppBar 标题
- ✅ 所有 Dialog (AlertDialog, SimpleDialog 等)
- ✅ ListTile 文本
- ✅ Text Widget（所有未明确指定字体的文本）
- ✅ 按钮文字
- ✅ 输入框提示文字
- ✅ 菜单文字

## 相关实现

### SettingsProvider 中的方法

```dart
/// 更新应用 UI 字体
Future<void> setAppFontFamily(String fontFamily) async {
  _settings = _settings.copyWith(appFontFamily: fontFamily);
  notifyListeners();
  await _saveSettings();
}

/// 更新提词器正文字体
Future<void> setTeleprompterFontFamily(String fontFamily) async {
  await _setAndSave(overrideData: {'teleprompterFontFamily': fontFamily});
}
```

### 应用设置页面

**文件**: `lib/pages/settings_page.dart`

应用字体选择使用 SimpleDialog，显示预设字体列表，用户可以选择任意一个应用到 UI。

### 提词器文本层

**文件**: `lib/widgets/teleprompter_text_layer.dart`

构建 RichText 时使用 `teleprompterFontFamily` 参数，独立于应用 UI 字体。
